COMP411/723/802 @ KNU, Autumn 2026

Computer Architecture

This course introduces the fundamental principles of modern computer architecture, including instruction set architecture, processor design, pipelining, memory hierarchy, out-of-order execution, parallelism, performance evaluation, near-data processing, and emerging computer systems.

Lecture materials are organized by chapter and slide. Each slide can be viewed individually, and students may use the discussion section to ask questions, exchange ideas, and discuss the lecture material.
